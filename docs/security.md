# Seguridad

- Emparejamiento ADB solo con consentimiento visible en la TV.
- No ejecutar comandos arbitrarios recibidos por HTTP.
- No exponer el servicio en Internet.
- Autenticación obligatoria al habilitar acceso LAN.
- Operaciones destructivas siempre requieren confirmación.
- No sugerir quitar paquetes del sistema esenciales.
- No guardar secretos ni claves ADB en Git.
